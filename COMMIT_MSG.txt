feat: Implement fast lane commands for real-time configuration

## Overview

Implement fast lane commands that allow users to quickly adjust agent
configuration at runtime without restarting or modifying config files.

## Changes

### 1. New Fast Lane Module (agent/fastlane/__init__.py)

- FastLaneCommands class for command processing
- Supported commands:
  - /thinking <level> - Set thinking level (off, minimal, low, medium, high)
  - /reasoning <on|off> - Toggle reasoning replay
  - /status - Show current configuration
  - /help - Show help message
- Automatic thinking level update across agent and heartbeat

### 2. Agent Integration (agent/core.py)

- Process fast lane commands before LLM pipeline
- Fast lane commands bypass LLM and execute immediately
- Agent's think_level updated in real-time
- Heartbeat updated if enabled

### 3. Tests (tests/test_fastlane.py)

- 22 tests covering all fast lane functionality
- Tests for command parsing, processing, and integration
- Tests for /thinking, /reasoning, /status, /help commands

## Usage

# Change thinking level
/thinking high      # Enable deep thinking
/thinking off      # Quick responses

# Toggle reasoning
/reasoning on      # Show internal reasoning
/reasoning off     # Hide reasoning

# View status
/status             # Show current configuration

# Get help
/help              # Show available commands
