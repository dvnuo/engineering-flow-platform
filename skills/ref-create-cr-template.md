# create-cr PR template (compact)

## Title guidance
- Use imperative mood and include scope when possible.
- Format suggestion: `<scope>: <what changed>`.

## Summary
- What changed
- Why it changed
- User or system impact

## Files/Areas Changed
- List key files or components touched.

## Testing
- Commands run and outcomes.
- Note any gaps if tests were not run.

## Risks / Notes
- Known risks, migrations, follow-ups, or reviewer focus areas.
